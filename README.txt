مُفرِّغ المحاضرات — تفريغ صوتي حقيقي (V4)

التشغيل:
1) ثبّت Python 3.10 أو أحدث.
2) ثبّت ffmpeg (مهم للمحاضرات الطويلة والفيديو):
   Windows: winget install ffmpeg
   macOS:   brew install ffmpeg
   Linux:   sudo apt install ffmpeg
3) داخل المجلد: pip install -r requirements.txt
4) انسخ .env.example إلى ملف اسمه .env وضع مفتاحك (يبدأ بـ sk-).
5) شغّل: python app.py
6) افتح: http://127.0.0.1:5000

الجديد في V4 (للطلبة):
- وضع "مذاكرة": ملخص + 10 أسئلة اختيار من متعدد بإجاباتها + مصطلحات للحفظ + النص الكامل.
- توقيت ⏱ قبل كل جزء عشان ترجع للمكان في التسجيل (ممكن تقفله).
- تقدير تكلفة التفريغ قبل ما تبدأ (السعر في PRICE_PER_MIN في .env لو اتغيّر).
- سجل "محاضراتي السابقة": بيتحفظ في مجلد history على جهازك، وتفتح وتعدّل وتنزّل في أي وقت.
- تحسين الصوت للتسجيلات الضعيفة (يشيل الدوشة ويرفع الصوت الواطي، محتاج ffmpeg).
- مواد محفوظة: احفظ مصطلحات كل مادة واختارها بضغطة.

الجديد في V3:
- التقسيم بقى عند أقرب لحظة صمت لكل 10 دقايق، فمفيش كلمة بتتقطع بين جزءين.
- لو حصل خطأ في النص أو الملخص، اللي اتفرّغ يتحفظ ويظهر مع تنبيه بدل ما يضيع.
- المحاضرة الطويلة (أكتر من ساعة) ما بتتمسحش من الذاكرة وهي شغالة.
- زرار إلغاء، واستكمال المتابعة بعد تحديث الصفحة.
- رسائل خطأ أدق (رصيد خلص / ضغط طلبات / ملف مرفوض).
- فحص المفتاح (sk-) وقبول .env المحفوظ من Notepad.
- Word: خط عربي صحيح، صفحة A4، عناوين الملخص.

ملاحظات:
- بدون ffmpeg: الحد 24MB والصيغ MP3/M4A/WAV/MP4/OGG/FLAC/WEBM فقط.
- لا ترفع ملف .env إلى مستودع عام.
- لو هتنشره على الإنترنت أضف تسجيل دخول.

===== مجاني بالكامل (V4.2) =====
- التفريغ: Groq (Whisper) مجاني بدون بطاقة. خد مفتاح من console.groq.com/keys وحطه في GROQ_API_KEY.
  الحد المجاني: ساعتين صوت كل ساعة و8 ساعات يوميًا (ممكن يتغيّر، راجع صفحة Groq).
- الملخص والأسئلة: بنفس المفتاح، بس بياخد وقت أطول في الخطة المجانية (بيستنى بين الطلبات).
- لو عايزة OpenAI بدل Groq: PROVIDER=openai و OPENAI_API_KEY (مدفوع).

===== استضافة مجانية على Hugging Face Spaces =====
1) أنشئي حساب على huggingface.co ثم New Space > SDK: Docker > CPU basic (مجاني).
2) ارفعي ملفات المشروع كلها (أو اربطيه بـ git).
3) Settings > Variables and secrets: ضيفي GROQ_API_KEY و APP_PASSWORD و SECRET_KEY كـ Secrets.
4) افتحي الرابط المباشر https://اسم-المستخدم-اسم-السبيس.hf.space (مش صفحة huggingface.co) وسجلي الدخول.
- الـ Space بينام بعد 48 ساعة بدون استخدام ويصحى في ~دقيقة. والسجل بيتمسح عند إعادة التشغيل، فنزّلي نتايجك.
5) على الموبايل: كروم > ⋮ > تثبيت التطبيق.
6) APK (اختياري، مجاني على GitHub Actions): ضيفي متغير SERVER_URL برابط الـ Space في
   Settings > Secrets and variables > Actions > Variables ثم Actions > Build APK > Run workflow.
